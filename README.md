### 🎙️ Arabic ASR with Fine-Tuned Whisper
Fine-tuning Whisper Small on an Egyptian Arabic speech dataset to convert speech into written Arabic text.

- Model training and evaluation with validation loss, WER, and CER.

### 🗣️ Egyptian Arabic ASR with CNN-BiLSTM
A CTC-based acoustic model for Egyptian Arabic speech recognition, with an optional KenLM language model for decoding.

**Highlights**
- MFCC, delta, and delta-delta features (120 features per time step).
- CNN-residual-BiLSTM acoustic model and WER/CER evaluation.
- KenLM 5-gram beam-search decoding and Gradio interface.

**Stack:** PyTorch · librosa · CTC · KenLM · pyctcdecode

**Stack:** Deep Learning · CNN-LSTM · EEG · Signal Processing

**Stack:** PyTorch · scikit-learn · CNNs · OpenCV

Machine-learning pipelines for forecasting solar PV output from meteorological data.

Constraint-based university timetable generation alongside an unsupervised Iris dataset analysis.

**Highlights**

- Two PCA components captured 95.8% of Iris dataset variance.
